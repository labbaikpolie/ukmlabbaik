# Website Resmi UKM LABBAIK

Website resmi **Unit Kegiatan Mahasiswa LABBAIK Politeknik Negeri Jember** yang berfungsi sebagai media informasi, publikasi kegiatan, dan pengenalan organisasi kepada mahasiswa serta masyarakat.

🌐 **Website:** [https://ukmlabbaik.rf.gd](https://ukmlabbaik.rf.gd)  
💻 **Repository:** [github.com/labbaikpolie/ukmlabbaik](https://github.com/labbaikpolie/ukmlabbaik)

## 📖 Tentang Proyek

UKM LABBAIK merupakan Unit Kegiatan Mahasiswa di lingkungan Politeknik Negeri Jember yang menjadi wadah kegiatan keislaman dan pengembangan diri mahasiswa.

Website ini dikembangkan sebagai sarana penyampaian informasi organisasi secara digital. Melalui website ini, pengunjung dapat mengenal profil organisasi, mengetahui visi dan misi, serta memperoleh informasi mengenai kegiatan dan program kerja UKM LABBAIK.

Pengembangan website juga berfokus pada peningkatan tampilan visual, kemudahan navigasi, dan kenyamanan pengguna saat mengakses website melalui berbagai perangkat.

## ✨ Fitur Website

- **Profil Organisasi** — Menampilkan informasi mengenai UKM LABBAIK.
- **Visi dan Misi** — Menyajikan tujuan dan arah organisasi.
- **Informasi Kegiatan** — Menjadi media publikasi kegiatan dan program kerja organisasi.
- **Desain Responsif** — Menyesuaikan tampilan website dengan ukuran layar desktop maupun perangkat mobile.
- **Navigasi yang Mudah** — Memudahkan pengunjung menemukan informasi yang dibutuhkan.
- **Identitas Visual Organisasi** — Menggunakan perpaduan warna biru, kuning, dan putih untuk mendukung konsistensi tampilan website.

## 🛠️ Teknologi yang Digunakan

Teknologi yang digunakan perlu disesuaikan dengan implementasi aktual di dalam repository.

- **HTML5** — Menyusun struktur halaman website.
- **CSS3** — Mengatur tampilan, tata letak, warna, dan responsivitas website.
- **JavaScript** — Mendukung interaksi dan fungsi dinamis pada halaman website.
- **InfinityFree** — Layanan hosting untuk publikasi website.

## 🎨 Konsep Desain

Website UKM LABBAIK dirancang dengan pendekatan modern, bersih, dan informatif. Konsep desain berfokus pada:

- Konsistensi identitas visual organisasi.
- Penyajian informasi yang terstruktur.
- Tata letak yang nyaman dan mudah dipahami.
- Responsivitas pada perangkat desktop dan mobile.
- Pengalaman pengguna yang sederhana dan efektif.

## 🚀 Cara Menjalankan Proyek

### 1. Clone Repository

Jalankan perintah berikut melalui terminal:

```bash
git clone https://github.com/labbaikpolie/ukmlabbaik.git
```

### 2. Masuk ke Direktori Proyek

```bash
cd ukmlabbaik
```

### 3. Jalankan Website

Buka file `index.html` menggunakan browser atau jalankan melalui ekstensi Live Server di Visual Studio Code, sesuai struktur proyek.

Apabila website menggunakan framework atau dependensi tambahan, sesuaikan langkah menjalankannya dengan konfigurasi yang tersedia di repository.
